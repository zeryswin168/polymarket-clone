# Polymarket Clone — Prediction Market Development

**Polymarket-style prediction market development, clone script & white-label solutions.**

## Quick Start

```bash
git clone https://github.com/zeryswin168/polymarket-clone.git
cd polymarket-clone
npm install
npm run dev
```

Open the local address printed by Vite.

Build the frontend:

```bash
npm run build
```
